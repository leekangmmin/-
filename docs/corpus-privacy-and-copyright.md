# 코퍼스 개인정보·저작권 정책

- 원본 답안, 유료 자료, 공식·독점 자료와 처리 결과는 로컬 비공개 디렉터리에만 둔다.
- 출처나 허가 상태가 불명확하면 `unknown`으로 보고 재배포를 금지한다.
- 이메일 주소와 전화번호 형태는 수집 단계에서 마스킹한다.
- 공개 코드, 테스트, 문서와 UI에는 원문 답안이나 긴 답안 틀을 넣지 않는다.
- 공개 가능한 산출물은 집계 통계, 추상적 구조 정의, 짧은 범용 문장 시작 표현뿐이다.
- 코퍼스 원문을 클라우드 AI로 전송하지 않으며, 운영 점수는 결정론적 Offline Core가 계산한다.

이 앱의 결과는 ETS의 공식 채점이나 정확도 인증을 의미하지 않는다.
