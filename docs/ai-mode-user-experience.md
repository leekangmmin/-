# AI Mode User Experience (Phase 7)

**Date**: 2026-07-08

## 3계층 AI 모드

### Mode A — 기본 분석 (Offline Core)

- **사용자 표시**: "기본 분석" ✅
- **상태**: 항상 사용 가능
- **설명**: "문법·구조·어휘 기반으로 분석해요. 인터넷이나 API 키가 필요하지 않아요."
- **점수 영향**: 공식 표시 점수
- **아이콘**: 체크마크

### Mode B — 로컬 AI 분석

- **사용자 표시**: "로컬 AI 분석"
- **상태**: 사용 불가 / 사용 가능 / 로드 중 / 오류
- **설명**: "설치된 로컬 AI 모델을 사용해 더 자세한 표현 개선을 제안해요. 답안은 기기 밖으로 나가지 않아요."
- **점수 영향**: 없음 (향상/보조 용도만)
- **하위 상태**:
  - 룰 기반: "기본 로컬 분석" (기본값, 항상 가능)
  - Ollama: "Ollama 로컬 모델"
  - llama.cpp: "llama.cpp 로컬 서버"
  - MLX: "Apple Neural Engine 로컬 모델"

### Mode C — 클라우드 AI 분석

- **사용자 표시**: "클라우드 AI 분석"
- **상태**: 꺼짐 (기본) / 설정됨 / 오류
- **설명**: "선택한 외부 AI 서비스로 답안이 전송될 수 있어요. 사용자가 직접 켠 경우에만 작동해요."
- **점수 영향**: 없음
- **하위 제공자**: OpenAI, Claude, Gemini, DeepSeek

## 용어 규칙

### 사용자에게 보여주는 용어
- "기본 분석" (Offline Core)
- "로컬 AI 분석" (Local AI)
- "클라우드 AI 분석" (Cloud AI)

### 숨기는 용어 (고급 설정 패널에만)
- provider, endpoint, shadow, calibration, schema
- model version, inference, token

### 개인정보 문구
- 기본 분석: "기기 안에서 바로 분석해요. 인터넷이나 API 키가 필요하지 않아요."
- 로컬 AI: "설치된 로컬 AI 모델을 사용해 더 자세한 표현 개선을 제안해요. 답안은 기기 밖으로 나가지 않아요."
- 클라우드 AI: "선택한 외부 AI 서비스로 답안이 전송될 수 있어요. 사용자가 직접 켠 경우에만 작동해요."
