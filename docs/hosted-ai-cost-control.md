# Hosted AI Cost Control

public hosted AI를 열기 전 필수 조건:

- per-IP rate limit
- per-account daily quota
- guest quota
- max essay length
- request timeout
- provider timeout
- queue 또는 concurrency limit
- monthly budget cap
- cost estimation
- usage logging without essay text
- admin dashboard
- abuse blocklist
- fallback to Offline Core

무료 서비스에서 무제한 AI를 약속하지 않는다. 예산이 없거나 통제 장치가 없으면 hosted AI는 꺼둔다.
