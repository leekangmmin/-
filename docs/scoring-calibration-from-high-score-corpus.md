# 고득점 코퍼스 기반 채점 캘리브레이션

## 현재 상태

2026-07-12에 제공된 24쪽 PDF를 로컬에서 확인했다. 답안 경계를 기준으로 41개(토론 16개, 이메일 25개)를 인식했으며, 원문은 저장소로 복사하거나 커밋하지 않았다. 평균 분량은 토론 149.3단어, 이메일 126.7단어였다.

이번 변경은 채점 공식과 가중치를 변경하지 않는다. 엔진 공식 버전은 2.1.0 그대로이며, 구조 감지 결과는 설명형 피드백과 비공개 평가 도구에만 사용한다. 따라서 전후 점수 변화는 0으로 기대된다.

현재 공식으로 비공개 집계 평가한 결과 토론 평균은 3.594/5, false-low 비율은 0%였다. 이메일 평균은 2.740/5, false-low 비율은 52%였다. 이메일의 높은 false-low는 고득점 구조를 점수에 즉시 반영해야 한다는 결론이 아니라, 현행 공식이 이메일의 목적 달성과 정중성을 충분히 모델링하는지 전문가 라벨로 검증해야 한다는 신호다. 구조 감지율은 토론 98.2%, 이메일 90.3%였다.

## 관찰한 추상 패턴

- 토론: 입장, 다른 견해 반응, 이유, 예시, 결과 설명, 재강조
- 이메일: 인사, 목적, 구체 상황, 정중한 요청, 후속 조치, 감사·맺음말
- 공통: 명시적 연결, 단락별 기능 분리, 요구사항에 대한 직접 응답

## 한계와 변경 게이트

자료의 출처·허가와 대표성이 독립적으로 검증되지 않았고 표본 편향 가능성이 있다. 따라서 공식 점수 조정은 하지 않았다. 향후 가중치 변경 전에는 허가된 비공개 표본의 유형별 수, false-low 비율, 전문가 라벨과의 오차를 집계 수준으로 비교해야 한다. ETS 공식 정확도를 주장하지 않는다.
