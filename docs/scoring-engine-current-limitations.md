# Scoring Engine Current Limitations

- 전문가 채점 골드 데이터가 없어 실제 정확도·일치도를 아직 증명하지 못했다.
- 합성 fixture는 회귀 방지용이지 TOEFL 점수 정확도의 증거가 아니다.
- 오프라인 엔진은 의미·논리·관용적 어휘 정확성을 완전히 판단하지 못한다.
- 프롬프트 표면 진단은 복잡한 바꿔쓰기와 동의어를 놓칠 수 있어 점수에 반영하지 않는다.
- 문법 규칙은 지시 대상, 일부 품사 오류, 복잡한 collocation을 놓칠 수 있다.
- 0.5 반올림 경계에서 작은 차이가 표시 점수를 바꿀 수 있다.
- 클라우드 AI는 사용자가 명시적으로 켠 경우에만 점수에 반영되며, 공급자별 편차가 있을 수 있다.
- 단일 과제 점수로 전체 Writing 섹션 1–6 밴드를 계산하지 않는다.
