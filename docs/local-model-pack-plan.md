# Local Model Pack Plan (Phase 7)

**Date**: 2026-07-08
**Status**: 계획 단계 (실제 모델은 아직 번들링되지 않음)

---

## 핵심 원칙

- 앱 번들에는 모델 파일을 포함하지 않는다 (기본 설치 크기는 작게 유지).
- 모델 팩은 사용자가 명시적으로 선택/다운로드하는 별도 구성요소다.
- 무단 다운로드는 절대 하지 않는다.
- 라이선스, 체크섬, 메모리 요구량을 모두 확인하기 전에는 어떤 모델도 포함하지 않는다.

---

## 후보 모델 패밀리

| 모델 | 라이선스 | 상업적 사용 | 크기(Q4) | 메모리 요구 | Mac 지원 |

**검증 우선순위**: Mistral 7B (라이선스 명확, 크기 적절, Mac 지원 확실)

---

## 배포 방식

### 방식 A — 앱 내 다운로더 (권장, Phase 8)

- 사용자가 설정 화면에서 모델 선택 후 다운로드 버튼 클릭
- 체크섬(SHA-256) 자동 검증
- 저장 위치: `~/Library/Application Support/토플첨삭기/models/`
- 제거 버튼 제공
- 다운로드 소스: Hugging Face / 직접 호스팅 (URL 검증 필요)

### 방식 B — 수동 설치

- 사용자가 GGUF 파일을 직접 준비
- 설정에서 모델 경로 지정
- 앱이 체크섬과 형식을 검증

---

## 체크섬 전략

- 모델 배포 시 SHA-256 체크섬을 함께 게시
- 다운로드 후 자동 검증
- 검증 실패 시 모델 로드 거부
- 체크섬은 manifest.json 파일로 관리

---

## 메모리 요구량 확인

- 모델 로드 전 시스템 RAM 확인 (psutil)
- 실제 여유 메모리가 모델 요구량보다 충분한지 확인
- 부족 시 경고 후 fallback (RuleLocalAIProvider)

---

## 사용자 동의

- 모델 다운로드 전 라이선스 동의 화면 표시
- 개인정보 처리 방식 설명 (로컬 전용, 네트워크 전송 없음)
- 다운로드/설치/제거 모두 사용자 액션으로만 수행

---

## 제거

- 설정 > 로컬 AI 관리 > 모델 제거 버튼
- 모델 파일과 캐시를 안전하게 삭제
- 제거 후 자동으로 Offline Core로 폴백

---

## 업데이트

- 새 모델 버전 출시 시 알림 (선택적)
- 기존 사용자 데이터 보존하며 모델만 교체
- 자동 업데이트 없음 — 항상 사용자 확인

---

## 현재 상태

- **어떤 모델도 번들링되지 않음**
- **어떤 모델도 다운로드되지 않음**
- 계획은 확정되었으나 구현은 Phase 8 예정
- 현재 Local AI는 RuleLocalAIProvider만 실제 동작
- Ollama/llama.cpp는 감지만 하고 실질적 추론은 미구현

---

## 품질 리스크

- 로컬 LLM의 TOEFL 채점 정확도는 검증되지 않음
- 전문가 점수와의 상관관계 분석 필요
- 모델 편향(bias) 위험 존재
- 하드웨어 가변성으로 인한 품질 편차 가능
